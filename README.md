# Hi, I'm Valentina Alarcon

I'm an automation engineer with four years of experience, most of them in QA automation, and I now focus on AI engineering: AI agents that use tools to automate work on business documents and systems.

I test what I build the way I test any other software: thresholds fixed before the run, measurements against labelled data or the real system, and a README that says where the numbers come from and what the limits are.

**What I work with:** Python, TypeScript, FastAPI, Playwright, Selenium, Cypress, pytest, Docker, GitHub Actions, PostgreSQL, n8n, LLM APIs and local models with Ollama.

## Where to look

My work is in one portfolio: [**qa-automation-portfolio**](https://github.com/valarcon1226/qa-automation-portfolio). Good places to start:

- [Document extraction](https://github.com/valarcon1226/qa-automation-portfolio/tree/main/invoice-processor): invoices and ACORD 25 insurance certificates from PDF and Excel, by regular expressions or a language model, with the page and text fragment behind every field, measured on 40 labelled documents.
- [Browser automation that writes](https://github.com/valarcon1226/qa-automation-portfolio/tree/main/playwright-ts-parabank): Playwright in TypeScript types extracted records into a web form, with validation, retries and a guarantee that nothing is submitted twice.
- [Model and agent evaluations](https://github.com/valarcon1226/qa-automation-portfolio#evaluating-models-and-agents): a RAG assistant, a tool-using agent over MCP and a test case generator, each with thresholds written before the run.
- [QA on real open-source systems](https://github.com/valarcon1226/qa-automation-portfolio#qa-on-real-open-source-systems): Saleor, Paperless-ngx, Debezium, Keycloak and LiteLLM under concurrency, failures and version upgrades.

Also: [ig-mealplan-rag](https://github.com/valarcon1226/ig-mealplan-rag), a RAG app that turns Instagram recipes into a meal plan, and [ibm-rag-agentic-ai-labs](https://github.com/valarcon1226/ibm-rag-agentic-ai-labs), my coursework from the IBM RAG and Agentic AI certificate.
